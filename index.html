Catatan rilis · CKG Sekolah Auto Input

Copas langsung ke template, dan tombol muat ulang ekstensi

Dua pembaruan untuk operator: template Excel sekarang boleh diisi dengan copas dari file lain, dan panel punya tombol untuk menyambung ulang ke halaman CKG bila statusnya macet di "Halaman belum siap".

v0.28.0 & v0.28.16 Oktober 2026Belum diuji dengan file copas asli operator
v0.28.0

Copas langsung ke template

Masalahnya

Template sudah berformat Teks, tetapi saat menempel (Ctrl+V) dari file Excel lain, format sel ikut tertimpa. Akibatnya tanggal lahir, NIK, dan nomor WhatsApp terbaca dalam bentuk lain dan baris ditolak. File Excel biasa tidak bisa mengunci format saat copas.

Yang berubah

Template tidak dikunci. Ekstensi yang menyesuaikan format saat file diunggah. Kolom template tidak berubah, jadi file lama tetap bisa dipakai. Berlaku untuk template CKG Sekolah, CKG Umum, Konfirmasi Hadir, dan Input Pemeriksaan.

Yang tetap ditolak, dengan alasan yang jelas

BalikpapanDitolak tidak memuat tanggal

Kenapa NIK berbentuk angka ditolak?

Excel hanya menyimpan 15 digit angka. NIK 16 digit yang di file sumber sudah tersimpan sebagai angka kehilangan digit terakhirnya. Ekstensi tidak menebak, karena NIK yang salah satu digit bisa mendaftarkan orang lain. Perbaikannya: ubah kolom NIK di file sumber menjadi Teks, ketik ulang NIK-nya, lalu salin lagi.

v0.28.1

Panel tidak lagi macet di "Halaman belum siap"

Masalahnya

Operator sudah berada di CKG Sekolah → Cari/Daftarkan Individu, tetapi panel tetap menampilkan "Halaman belum siap". Ini terjadi bila ekstensi diperbarui sementara tab CKG belum di-refresh, sehingga sambungan ekstensi ke halaman terputus.

Yang berubah

  • Bila sambungan terputus, panel kini menulis: "Ekstensi belum terhubung ke halaman ini. Refresh tab CKG (tekan F5), lalu tunggu sampai tabel tampil."
  • Build debug menyambung ulang sendiri ke tab CKG tanpa perlu refresh.
  • Mode Konfirmasi Hadir tidak lagi menyuruh "unduh template lalu upload file". Pesannya sekarang: "Pilih Sekolah dan Kelas di website, lalu tekan MULAI."

Tombol muat ulang ekstensi

Tombol Muat ulang ekstensi muncul di bawah status saat halaman belum siap, dan tombol Muat ulang selalu ada di bagian bawah panel.

  1. Tekan tombolnya, lalu baca dan setujui konfirmasi yang muncul.
  2. Ekstensi dimuat ulang, lalu semua tab CKG di-refresh otomatis.
  3. Panel ikut tertutup. Setelah halaman CKG tampil, buka lagi lewat ikon ekstensi.
  • Tombol ditolak saat proses pendaftaran atau konfirmasi sedang berjalan, atau Input Pemeriksaan sedang mengisi. Tekan JEDA atau STOP lebih dulu.
  • Progres sesi tetap tersimpan. Isian formulir di tab CKG yang belum disimpan akan hilang, dan file yang sudah diunggah tetapi belum dimulai perlu diunggah lagi.
  • Tidak ada izin baru yang diminta.
Pertama kali memasang v0.28.1

Versi lama belum punya tombol ini. Buka chrome://extensions, tekan Reload pada CKG Sekolah Auto Input, lalu tekan F5 di tab CKG. Sesudah itu tombolnya bisa dipakai.
